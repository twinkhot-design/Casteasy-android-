# Cast Easy — بثّ إلى التلفزيون

مشروع Android أولي بلغة Kotlin لاكتشاف Chromecast وإرسال رابط وسائط مباشر متوافق باستخدام Google Cast SDK.

## الحالة الحالية
- واجهة عربية بسيطة.
- زر اختيار جهاز Cast عبر MediaRouteButton.
- إرسال روابط وسائط مباشرة مثل MP4 وHLS (`.m3u8`) عندما تكون متاحة من الشبكة ويقبلها Chromecast.
- **ليس APK جاهزًا**؛ يلزم بناء المشروع باستخدام Android Studio وAndroid SDK.
- **بث الشاشة بالكامل غير منفذ في هذه النسخة**. MediaProjection يلتقط الشاشة لكنه لا يجعل Chromecast يستقبل البث تلقائيًا. يتطلب هذا مسار نقل فيديو متوافقًا، وغالبًا تطبيق استقبال مخصصًا/تقنية مثل WebRTC أو حل استقبال مناسب.
- **الملفات المحلية غير منفذة بعد**. يلزم تقديمها عبر خادم محلي يمكن لجهاز Chromecast الوصول إليه، مع مراعاة قيود الشبكة وHTTPS/HTTP.

## البناء
1. ثبّت Android Studio حديثًا مع Android SDK Platform 35.
2. افتح مجلد المشروع `CastEasy` في Android Studio.
3. اسمح بمزامنة Gradle وتنزيل الاعتماديات.
4. من قائمة Build اختر Build APK(s).
5. ستجد APK التجريبي عادة في `app/build/outputs/apk/debug/app-debug.apk`.

## التشغيل
- الهاتف وChromecast يجب أن يكونا على شبكة Wi-Fi نفسها.
- افتح التطبيق، واضغط أيقونة البث، واختر Chromecast.
- الصق رابط ملف وسائط مباشرًا يمكن لجهاز Chromecast الوصول إليه، ثم اضغط «بث الرابط».
- روابط صفحات الويب العادية أو روابط TikTok ليست بالضرورة روابط وسائط مباشرة، ولذلك قد لا تعمل عبر حقل الرابط.
